# Analysis decisions

## Evidence hierarchy

The online condition-by-time estimate is the principal test of whether visual art produces a change beyond an active cultural comparison. Separate within-condition changes are descriptive secondary estimates. The in-person study contributes ecologically grounded pre-post evidence but no controlled causal contrast. HEartS contributes adjusted population-level associations and is not combined numerically with state-anxiety outcomes.

## Anxiety direction

Anxiety change equals post minus pre. Negative values indicate improvement. This direction is used in raw changes, standardized effects, regression outcomes, confidence intervals, figures, and table notes.

## Trait anxiety

The Castellotti trait-anxiety interaction is reported in two forms. The unadjusted time-by-trait model is statistically significant. The interaction is no longer present after baseline state anxiety is included. The adjusted estimate governs interpretation, so the repository does not describe trait anxiety as a robust moderator.

## HEartS exposure

The primary exposure groups `rart8` into none, infrequent, regular, and weekly or daily. The primary models treat these groups as categorical. Ordered trend and the original seven-level coding are sensitivity analyses. The horizontal spacing in Figure 3 identifies ordered categories and does not imply equal exposure intervals.

## HEartS adjustment sets

Model 1 adjusts for age category and reconstructed six-category ethnicity. Model 2 adds education and arts-professional status. Model 3 adds self-rated health, mild activity, moderate activity, vigorous activity, and partner closeness. These sets reflect variables actually available in the public Dryad file.

## Unsupported analyses excluded

The public HEartS file does not contain usable gender, region, household income, living arrangement, continuous age, detailed health-condition variables, or survey calibration weights. Analyses requiring those fields are not claimed or implemented. Complete-case and imputed results are not contrasted because the variables used by the primary HEartS models are complete in the released analytical file.

## Multiplicity and interpretation

Primary estimates are interpreted through effect sizes and 95 percent confidence intervals. Holm correction is used for prespecified families of secondary acute outcomes. Benjamini-Hochberg correction is used for exploratory interaction families. Post-exposure aesthetic ratings are treated as correlates, not mediators.
