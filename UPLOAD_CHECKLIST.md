# GitHub upload checklist

- Upload the complete repository directory while preserving folder structure.
- Do not upload participant-level files from `data/raw/` or `data/processed/`.
- Confirm that `.gitignore` is present before adding locally downloaded data.
- Confirm that all three PDF files open from `results/figures/`.
- Enable the GitHub issue tracker for reproducibility questions.
- Create a versioned release after the repository files are final.
- Archive that release with Zenodo to obtain a permanent DOI before manuscript submission.
- Add the resulting repository DOI to the manuscript data-availability statement and to `CITATION.cff` in the archived release.
