# Results files

The `tables` directory contains comma-separated model and evidence-summary tables. The `figures` directory contains publication-ready PDF figures. The `machine-readable` directory contains the complete HEartS model object exported as JSON.

Stored outputs permit inspection before the source data are downloaded. Regenerating the workflow replaces generated tables and figures with results computed from the source files.

Figure 1 presents the cross-design framework. Figure 2 presents standardized acute anxiety changes with post minus pre coding. Figure 3 presents fully adjusted HEartS marginal patterns for MHC-SF and CES-D.
